# Bartosz Szubert

I lead new product introduction (NPI) projects in manufacturing: 20–30 in parallel, from the first alignment with the engineering centre to stable serial production.

Here I publish small AI agents built in n8n. Each one lets a language model do part of the work and delivers the result on a schedule. Most of them follow one pattern: source collection, fact verification, duplicate control and a human approval gate. In the newest one, a hard rule from the prompt is also checked in code before anything is sent. One of them works for an external user.

I build them to learn where these tools hold and where they break, before I run projects that depend on them.

I am doing a postgraduate programme in AI and data-driven business management (Biznes.AI) at Kozminski University in Warsaw.
